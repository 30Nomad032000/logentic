Sprint 5 Report

Hyper-Localized Multilingual Voice Assistant
Sprint: 5 of 6 Duration: Week 9 – 10 Team: Dev (Solo) Velocity: 18 / 18 pts

1. Sprint Goal

Edge-ready optimization, performance benchmarking, and deployment packaging. Due to budget constraints preventing Raspberry Pi 5 procurement, the sprint pivoted from physical edge deployment to simulated edge optimization — model quantization utilities, response caching, Docker containerization with resource limits, and comprehensive performance profiling.

2. Sprint Outcome

All 18 story points delivered. The system is now edge-optimized with caching, quantization tooling, Docker deployment, and a benchmarking suite proving sub-3-second latency under constrained resources.

Key Deliverables

  • Response caching module — LRU cache with TTL for translation, TTS, and LLM results
  • Model optimization utilities — memory profiling, quantization configs, edge feasibility estimation, lazy model loading
  • Performance benchmarking suite — CLI tool measuring latency (min/max/avg/p50/p95/p99), memory, and throughput per component
  • Docker containerization — multi-stage Dockerfile, docker-compose with 2-CPU / 4GB resource limits simulating edge constraints
  • Edge-optimized config profile — smallest models (Qwen3 0.6B Q4, IndicTrans2-Dist, MMS) for minimal footprint
  • Interim presentation — 18-slide HTML presentation for project review
