Sprint 1 Report

Hyper-Localized Multilingual Voice Assistant
Sprint: 1 of 6 Duration: Week 1 – 2 Team: Dev (Solo) Velocity: 21 / 21 pts

1. Sprint Goal

Establish the project foundation. Complete technology stack research and selection, design the system architecture, set up the development environment, and build proof-of-concept implementations for the core ASR and TTS components across Indian languages.

2. Sprint Outcome

All 21 story points delivered. Technology stack finalized, architecture designed, development environment configured, and working PoCs built for speech recognition and text-to-speech.

Key Deliverables

  • Technology selection document — ASR, TTS, LLM, translation, and agent framework options evaluated
  • System architecture diagram — three-layer edge-to-server design with component interfaces
  • Development environment — Python 3.10+, GPU/CUDA configured, project structure created
  • Whisper ASR PoC — working speech-to-text for Malayalam with >80% accuracy
  • Meta MMS ASR research — 1600+ language coverage evaluated for Indian languages
  • MMS-TTS PoC — offline text-to-speech for Malayalam with intelligible output
  • Cartesia TTS PoC — high-quality online TTS integration with API wrapper
  • TTS comparison report — quality, latency, and offline capability assessed across engines

6. Sprint Retrospective

What went well

  • All 15 tasks completed on schedule — 21/21 story points delivered
  • Technology research was thorough; confident in stack selections (Whisper, IndicTrans2, Qwen, LangGraph)
  • Both ASR and TTS proof-of-concepts produced working output for Malayalam
  • Project structure and dev environment set up cleanly from day one

What could improve

  • Whisper accuracy for Malayalam (~80%) is lower than Hindi (~92%) — need a specialized Indic ASR model
  • MMS-TTS voice quality is functional but robotic — explore higher-quality alternatives
  • Research tasks took slightly longer than estimated on day 1; adjusted pace for remaining days

Action items for Sprint 2

  • Integrate IndicTrans2 for bidirectional Malayalam–English translation
  • Set up Qwen 2.5 LLM for local conversational AI
  • Investigate distilled translation models for smaller memory footprint
