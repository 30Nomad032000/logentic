Sprint 3 Report

Hyper-Localized Multilingual Voice Assistant
Sprint: 3 of 6 Duration: Week 5 – 6 Team: Dev (Solo) Velocity: 21 / 21 pts

1. Sprint Goal

Working end-to-end voice assistant with API, upgraded models, and dashboard. Build the complete ASR→Translation→LLM→TTS pipeline, create REST and WebSocket APIs, upgrade to Pingala V1 ASR, add Indic Parler-TTS, and implement ONNX Runtime inference acceleration.

2. Sprint Outcome

All 21 story points delivered. Major model upgrades achieved alongside full pipeline integration and API development.

Key Deliverables

  • Pingala V1 ASR — 50%+ better accuracy (2.94% WER), runs on CPU
  • Pipecat pipeline framework — production-grade STT→LLM→TTS orchestration
  • Indic Parler-TTS Mini — 69 voices with emotion control
  • Chatterbox-Turbo 350M — low-compute alternative TTS engine
  • ONNX Runtime backend — accelerated inference for translation/ASR models
  • Streaming WebSocket endpoint — real-time audio via /ws/stream
  • Typed dataclass configuration — YAML-loaded config system
