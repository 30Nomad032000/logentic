Sprint 2 Report

Hyper-Localized Multilingual Voice Assistant
Sprint: 2 of 6 Duration: Week 3 – 4 Team: Dev (Solo) Velocity: 21 / 21 pts

1. Sprint Goal

Complete the translation layer and conversational AI. Build bidirectional Malayalam–English translation using IndicTrans2, integrate Qwen 2.5 LLM for response generation, add conversation memory, and validate translation quality across supported Indian languages.

2. Sprint Outcome

All 21 story points delivered. Full translation capability and conversational AI integrated.

Key Deliverables

  • IndicTrans2-Dist models — ~211M parameters, 5x smaller than original, same quality
  • Qwen3 LLM with llama.cpp GGUF backend — fast CPU inference for local deployment
  • Direct Indic-to-Indic translation without English pivot, supporting all 11 languages
  • Dual backend support — llamacpp + transformers for flexible deployment
  • Conversation memory — context retention across multi-turn dialogues
  • Translation quality validation — ~93% accuracy confirmed for Malayalam
